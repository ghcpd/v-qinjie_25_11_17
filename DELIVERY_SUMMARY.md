## 🚀 Get Started in 5 Minutes

```bash
# Navigate to framework
cd test_framework

# Windows:
setup.bat && run_tests.bat

# Linux/macOS:
chmod +x setup.sh run_tests.sh
./setup.sh && ./run_tests.sh

# Docker:
docker-compose up --build
```

**Results**: Check `reports/test_report_*.json`
